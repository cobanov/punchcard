Support

Last updated 25 August 2026

Email mertcobanov@gmail.com and you will get a reply from the person who built punchcard. Say what you were doing and which client you were in; it makes the answer faster.

How do I sign in?

With GitHub. One authorization signs you in and, at the same time, lets punchcard read the commits behind your work — there is no second setup step and no password to forget.

My commits are not showing up

In the order worth checking:

  • Were they pushed? A commit that only exists on your laptop is invisible to punchcard, because it asks GitHub. Push, and it will appear — the last seven days go back through the scanner every hour, so a commit written at 09:00 and pushed at 18:00 still finds its session.
  • Are you the author? punchcard attaches commits authored by your GitHub account, not everything that landed in the repository.
  • Was a timer running? Attribution is decided by time. If no timer covered the moment, the commits are not lost — they are shown on the Today screen as unmatched, ready to be turned into a record.
  • Is GitHub connected? Settings → Connections will say.

Branches are not a problem: punchcard walks every branch, not just the default one.

Do I have to link a repository to a project?

No. The scanner asks GitHub which repositories you pushed to and looks there. Linking a repository to a project is optional and does one thing: it sharpens the guess about which project a stretch of unmatched commits belongs to.

I forgot to start the timer

Look at the bottom of the Today screen. Commits pushed while nothing was running are grouped by the gaps between them and offered back to you with the time range they cover — pick a project and record it.

I started the wrong timer

Starting a new one stops the old one; you never end up with two running. Any finished session can be opened from the list and its project, note, start and end edited, or deleted outright.

My days are cut in the wrong place

Settings → Reporting → Timezone. Reports group by day in that zone, so a session that crosses midnight lands on the day you would say it belongs to. A new account starts at UTC.

Getting your data out

The account menu → Download my data gives you a JSON file with your projects, every session and the commits attached to them, plus your account details. The Analytics screen also exports the current range as CSV. No one has to approve either, and both are available at any time.

Deleting your account

Settings → Danger zone → Delete account. It is immediate and permanent, which is why it asks you to type your email address first.

Using punchcard from a terminal or a script

There is a command line client and a macOS menu bar app, both of which sign in through the same browser flow. For anything else there is an HTTP API; the documentation is at /docs.

Something is broken

Email the address above. If you were running a timer when it happened, say roughly when — the record is on the server, so it is usually recoverable.
