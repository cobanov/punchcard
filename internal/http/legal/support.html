Support

Last updated 10 August 2026

Email mertcobanov@gmail.com and you will get a reply from the person who built helva. Include the device and what you were doing; it makes the answer faster.

I forgot my password

helva has no self-service password reset yet. Email the address above from the address on the account and it will be sorted out by hand. If you signed in with Apple, Google or GitHub, there is no helva password at all — use the same button you used the first time.

Where did my tasks go?

helva keeps everything on the device first, so nothing is lost when the connection drops. If a device looks out of date, check that it is signed in to the same account and has been online since the change. Tasks sync in the background; there is no manual sync button because there is nothing to press.

Sharing a list

Open the list's menu and invite someone by email. They see that list and its tasks, and nothing else in your account. Either of you can add and complete tasks; the owner can remove access at any time.

Getting your data out

Settings → Data → Export my data gives you a JSON file with every list and task the account can reach, including deleted ones, plus your account details. No one has to approve it and it is available at any time.

Deleting your account

Settings → Data → Delete account, inside the app. It is immediate and permanent, which is why it asks you to type DELETE first. If you own a list you have shared, helva asks you to hand it over or stop sharing it first, so that other people's work does not disappear with yours.

Using helva from an assistant or a script

helva has an HTTP API and an MCP server. Create a token in Settings → Tokens, give it to the tool, and revoke it whenever you like. The API documentation is at /docs.

Something is broken

Email the address above. If the app cannot reach the server at all, it keeps working offline — your changes are safe on the device and will sync when the service is back.
