punchcard

Time tracking for developers, with the commits attached.

Start a timer against a project, say what you are doing, stop it. When you stop, punchcard fetches the commits you pushed during that stretch and attaches them to the record — so a day's log is not “3 hours, refactor” but “3 hours, refactor, 7 commits, these files”.

It works in reverse too: commits made while no timer was running come back as a suggested record. That is how a forgotten timer gets recovered — the evidence was on GitHub all along.
